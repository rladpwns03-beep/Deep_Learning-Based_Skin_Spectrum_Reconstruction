# BiGRU structure ablation (post hoc, exploratory)

**Status: post hoc, exploratory. Not preregistered; added after the ExternalTest6 results were seen.** The preregistered results (`results/final_comparison`, `results/external_test`, `results/union16`) are unchanged, and the ExternalTest6 configuration was not used. This document is generated by `scripts/ablation_bigru_structure.py --aggregate` and reports numbers only.

Units: 10^-3 absorbance. Subject value = mean of the metric over seeds. Difference = first model minus second model; the column "Difference < 0" counts subjects. The standard error is the between-subject SD of the paired difference divided by sqrt(n) (ddof = 1). p values (exact Wilcoxon signed-rank, sign test, two-sided) are descriptive and not corrected for multiple comparisons.

## 1. Variants and training

All variants use the same encoder (4 inputs per wavelength, one bidirectional GRU layer with hidden 8 per direction, shared Linear(16, 1) initialised to zero; 689 parameters). Only the assembly of the linear-layer output differs. In all variants A*(570) = h*.

| Variant | Assembly | Removed element | Identity holds by structure |
|---|---|---|---|
| BiGRU_ResidualSlope | A* = A_in + (h* − h_in)(b + r) | nothing (current structure) | yes |
| BiGRU_FullSlope | A* = A_in + (h* − h_in) s | Global Linear prior | yes |
| BiGRU_AdditiveCorrection | A* = A_in + g | Global Linear prior, proportionality to the HbI change | no |
| BiGRU_DirectOutput | A* = μ + σ f | Global Linear prior, proportionality to the HbI change, input pass-through | no |

Training (fixed before running): hidden 8, lr 3e-3, clip 1.0, Adam, full batch, subject-weighted MSE over the 30 wavelengths other than 570 nm, no slope penalty, 1,000 epochs with test metrics recorded at epochs 0, 25, 50, 100, 150, 200, 300, 500, 1000, seeds 0 to 4. Evaluation sets: Development10_LeaveOneSubjectOut (10 folds) and Union16_LeaveOneSubjectOut (16 folds), read from `data/splits_final/`. BiGRU_ResidualSlope at epoch 200 equals the frozen BiGRU setting (hidden 8, slope_l2 0, epoch 200).

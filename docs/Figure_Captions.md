# Figure captions

Generated by `scripts/make_figures.py` (`scripts/figure_captions.py`). Figures: `results/figures_final/presentation/` (12.0 in wide, 200 dpi, with title) and `results/figures_final/report/` (6.3 in wide, 600 dpi, no title). The numbers drawn in each figure are in `results/figures_final/plotted_data/`.

Conventions used in every figure: a point is one subject, the centre marker is the mean across subjects, and error bars are the standard error (between-subject SD / sqrt(n), ddof = 1). Difference = first model minus second model. No p values are shown.

## Figure06_ResidualSlope_VersusPersonalReference

Band-mean residual slope of each model against the personal reference residual slope of the same test subject.

- Panels: Rows: PLS_v2 (top) and BiGRU (bottom). Columns: Soret, Band 450-460, Q-band (570 nm excluded) and Red. Dotted line: y = x. Dashed lines: zero. Each panel lists the Pearson r and n for each cohort.
- Data: Development cohort: leave-one-subject-out, n = 10 subjects, hyperparameters tuned inside the training subjects of each fold. External cohort: n = 6 subjects, evaluated once with frozen settings (training = all 10 Development cohort subjects). Unit of analysis: subject. Residual slope of a model = (model prediction - Global Linear prediction) / change in HbI, averaged over the test pairs of a subject (pairs with zero change excluded). Personal reference = within-subject least-squares slope of the test subject minus the Global Linear slope; it is used for evaluation only.
- Markers, error bars, units: Points: individual subjects (filled circles: Development cohort; open triangles: External cohort). Units: absorbance per unit HbI. BiGRU subject values are the mean of the metric over seeds 0, 1 and 2.
- Notes: With n = 6 in the External cohort the uncertainty of r is large. The recomputed r values agree with the stored summary tables.
- Source: results/band_analysis/Development10_LeaveOneSubjectOut/residual_slope_per_subject.csv; results/external_test/residual_slope_per_subject.csv; the residual_slope_summary.csv files in the same folders

## SupplementaryFigure06_SHAP_InputGroupShare

Band-level SHAP values: share of seven input groups and the input group by output band map.

- Panels: (a) Share of the mean absolute SHAP value over the 30 output wavelengths for Global Linear, PLS_v2, BiGRU, PLS_v1 and Ridge. (b) Mean absolute SHAP value of each input group for each output band, for PLS_v2 and BiGRU; each map has its own grey scale.
- Data: Computed only on Development10_LeaveOneSubjectOut (900 test pairs, 10 folds). Exact Shapley values over 7 input groups (128 coalitions), background = 100 training pairs of the fold. BiGRU: computed per seed and then averaged.
- Markers, error bars, units: Panel (a): percent. Panel (b): 10^-3 absorbance.
- Notes: PLS_v2 and Ridge take the input in the form (change in HbI) x (A_in - A_in(570)), so the contributions of the input HbI group and of the spectral groups can cancel with opposite signs; group shares alone are not read as importance.

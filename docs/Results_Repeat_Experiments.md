# Repeated experiments (post hoc, exploratory)

**Status: post hoc, exploratory. Not preregistered; added after the ExternalTest6 results were seen.** The preregistered results are unchanged and the ExternalTest6 configuration (training = exactly the 10 Development cohort subjects, evaluation = the 6 External cohort subjects) is not among the splits. This document is generated by `scripts/run_repeat_experiments.py --aggregate` and reports numbers only.

Units: 10^-3 absorbance. Subject value = mean of the metric over all splits of a set in which the subject is a test subject (BiGRU: mean over seeds 0, 1, 2 first). Difference = first model minus second model; "Difference < 0" counts subjects. p values are descriptive, without correction for multiple comparisons. **Splits share subjects, so the standard deviation between splits is not the error of independent samples.**

Models: HbI-binned mean and Global Linear as before; PLS_v2 (number of components up to 10) and Ridge (alpha) selected inside the training subjects of every split; BiGRU with the frozen values (hidden 8, slope_l2 0, epoch 200) and BiGRU (fixed setting) (hidden 8, slope_l2 0.001, epoch 150), seeds 0, 1, 2. Intended exception: the two BiGRU settings were determined from results of the 10 Development cohort subjects, so when a Development cohort subject is a test subject, that subject took part in choosing the setting.
